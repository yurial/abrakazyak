# Индекс спецификаций «Abrakazyak»

Единая точка обнаружения спецификаций проекта. Каждая спецификация зарегистрирована одной строкой; статус синхронизирован со строкой `Status` в самом документе.

| Path | Reference | Status | Summary |
| --- | --- | --- | --- |
| specs/game.md | game | draft | Правила игры «Abrakazyak»: участники и очередь ходов, лимиты текста, видимость, завершение партии и сборка готового рассказа |
| specs/storage.md | storage | draft | Локальное хранение: черновик текущей партии с автосохранением и восстановлением, архив завершённых рассказов |
| specs/ui.md | ui | draft | Экраны приложения, каталог текстов на русском и английском, поведение ввода, навигация и локализация |
